# Missing artifacts and verification limits

1. **Per-request GPT completion usage:** The supplied manuscript states that no GPT-4o-mini request exceeded 1,024 completion tokens. Released GPT records contain aggregate run/task usage, not per-request completion counts; the claim is not independently verifiable from this package.
2. **Original GPT MD and SED token usage:** Their saved 65-task artifacts have no numeric prompt/completion usage. They are reported as `not recorded`, never imputed from another run. GPT SED Fresh has complete usage records and is kept separate. Gemini MD/SED saved summaries contain a zero thoughts-token aggregate, but per-call records do not establish that every call measured zero thinking tokens.
3. **Historical source revision:** The saved task artifacts do not establish a byte-identical historical code revision for every legacy GPT, Qwen, and Gemini runner. The package includes existing source files and records source/release hashes; where task metadata records a historical runner SHA, it remains in the manifest.
4. **Model snapshots:** GPT legacy MD/SED do not save provider response-model IDs; Gemini records an API model ID but not a separate provider checkpoint revision. Qwen records a model revision in task metadata. Do not infer unrecorded revisions.
5. **Qwen EDA recovery lineage:** Tasks 1–2 reused completed smoke artifacts. Task 59 was recovered after parse/encoding errors. The final Task 59 artifact is included; the three parse-failure attempts' numeric usage fields are separately included in `results/qwen_eda_recovery_usage.json`. Raw failed request/response content is not redistributed.
6. **Complete API transcript:** This minimal release contains public discussion, ballots, fact assignments, and usage totals. Raw provider request/response traces, request IDs, and historical error logs are not redistributed.
7. **Publication rights for generated outputs:** The upstream HiddenBench benchmark is marked MIT by its official distribution. Provider-specific terms governing release of generated model outputs were not independently established from saved files; check provider terms at upload time.
